# Domain Docs

This is a single-context repository: `GLOSSARY.md` and `docs/adr/` live at the root.
Before exploring, read `GLOSSARY.md` and relevant ADRs when present. If absent, proceed silently; domain modeling creates them lazily when terms or decisions are resolved.
Use the glossary's vocabulary in code, issues, and proposals. Flag conflicts with an existing ADR explicitly rather than silently overriding it.
